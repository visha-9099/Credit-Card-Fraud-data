💳 Credit Card Fraud Detection Dataset
This repository contains a credit card fraud dataset, designed to help data scientists, financial analysts, and cybersecurity professionals detect fraudulent
transactions using machine learning and statistical methods. The dataset includes realistic transaction records with labels indicating whether a transaction
is fraudulent or legitimate.

📌 Dataset Features
🏦 Transaction Details
Transaction ID: Unique identifier for each transaction.
Timestamp: Time of transaction (seconds elapsed from a reference point).
Transaction Amount: Value of the transaction.
Merchant Information: Merchant category, location (if available).

🔍 User & Account Information
Customer ID: Unique identifier for each cardholder.
Account Age: Duration of the cardholder’s account.
Card Type: Debit, credit, premium, etc.

⚠️ Fraud Indicators
Transaction Frequency: Number of transactions within a given period.
Transaction Location: If a transaction occurs from an unusual location.
Merchant Type: High-risk merchants based on fraud history.

Fraud Label:
0 → Legitimate transaction
1 → Fraudulent transaction
🔍 Key Insights & Use Cases
🚨 Fraud Detection & Prevention
Identifying patterns in fraudulent transactions.
Detecting suspicious spending behavior.
Analyzing transaction anomalies based on location, frequency, and amount.

🤖 Machine Learning Applications
Supervised Learning: Training models to classify fraud vs. non-fraud transactions.
Anomaly Detection: Using unsupervised learning to identify unusual spending.
Real-Time Fraud Prevention: Developing automated systems for real-time fraud alerts.
